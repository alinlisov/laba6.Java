# Лабораторна робота №6 - Червоно-чорне дерево (Java)

ІС-42, Лісова Аліна

## Файли

- `src/Main.java` - консольне меню, введення з клавіатури, випадковий та впорядкований масиви.
- `src/RedBlackTree.java` - дерево пошуку, вставлення, видалення, обходи, відображення, перевірка властивостей.
- `src/RedBlackTreeTests.java` - автоматичне тестування без JUnit.


## Демонстрація роботи

1. Оберіть пункт `5` і задайте кількість чисел - програма покаже початковий масив і дерево.
2. Оберіть пункт `6` - ті **самі числа** сортуються і додаються до нового дерева за зростанням. Порівняйте два відображення дерева.
3. Оберіть пункт `7` і введіть числа вручну (через пробіл, кому або крапку з комою).
4. Перевірте обходи (пункт `3`), видалення (пункт `2`) та властивості (пункт `8`).

У дереві зберігаються тільки унікальні цілі числа. Позначення: `(R)` - червоний, `(B)` - чорний. На рисунку праві нащадки показані вище кореня, ліві - нижче.
